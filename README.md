# The Life Link website

Static site built with Astro and hosted on Vercel. Live at https://thelifelink.org once the domain is cut over.

## How it works

Every change merged into the `main` branch on GitHub rebuilds and republishes the site on Vercel. A pull request gets a private preview link first.

## Where things live

See `CLAUDE.md`. Short version: words are in `src/data/*.json`, shared facts in `src/data/site.ts`, layout in `src/pages/`, images in `public/assets/`.
